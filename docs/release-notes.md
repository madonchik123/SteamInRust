## SteamInRust 0.1.0, the first release

A native Steam client written in Rust: store, library, downloads, Steam Cloud,
friends and chat, community pages, inventory and market, all without a web
browser inside.

**Install:** download `SteamInRust-Setup-0.1.0.exe` below and run it. No
administrator rights needed. Future versions install themselves.

**Highlights**
- Store with native trailer playback, wishlist, cart and price history
- Library with collections, filters, Properties, DLC and Steam Cloud
- Own depot downloader with every Steam region and partner CDNs
- Steam features in games: our own steamclient for games without anti-cheat,
  the official client (started silently) for games with VAC, EAC or BattlEye
- Shift+Tab overlay with pinnable windows: game overview, achievements,
  friends, chat, notes, guides, discussions
- Friends, chat, profiles, community hubs, Workshop, guides, discussions
- Inventory and market with quick sell and Steam's real fees
- Sandboxed plugins, English and Russian, auto-updates

Windows may warn about an unrecognized app (the setup isn't code-signed yet):
choose **More info → Run anyway**. Check files against `SHA256SUMS.txt`.
